# Architecture Decision Records (ADRs)

An ADR is a short record of one significant decision: what was decided, why, and what was given up. Number the files in order (`0001-service-split.md`, `0002-java-21-and-gradle.md`, …). Never edit an accepted ADR. If a decision changes, write a new ADR that supersedes the old one.

## Template

```markdown
# NNNN. Title

- Status: Proposed | Accepted | Superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem or force makes this decision necessary?

## Decision
What we are doing.

## Alternatives considered
What else we looked at, and why we didn't choose it.

## Consequences
What gets easier, what gets harder, and what we now have to live with.
```
